# paper-reading skill

A Claude Code skill that turns an academic paper into a structured bilingual reading note, extracted from [pengsida/learning_research](https://github.com/pengsida/learning_research).

## Installation

Copy the `paper-reading/` folder into your Claude Code skills directory, then restart the session:

```bash
git clone git@github.com:wawabinger/paper-reading-skill.git
cp -R paper-reading-skill/paper-reading ~/.claude/skills/
```
